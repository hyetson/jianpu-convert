# 参考输出的音符字体试配

参考文件：`example/丝绸之路_竹笛分谱.pdf`。本轮只更换数字音符字体，不改变音高、时值、标题、调号/拍号和音乐符号的配置。

## 判断依据

- 参考 PDF 的普通数字音符主要以填充矢量路径绘制，缺少可直接追溯到字体名称的文本记录。
- 文本层中的 `SimSun` 多用于小节号、调号/拍号及文字；不能据此认定数字音符也使用宋体。
- 文件还包含 Bravura、Bravura-Text、Academico，以及名称被写成 `CIDFont+F1` 的 Maestro 字体子集。这些资源的存在不能证明普通音符数字采用其中任何一种字体。
- 对第一页人工确认的 0、2、5、6、7 五个字形进行高分辨率裁切，将候选字形归一化后比较轮廓重合度。本地候选中 Arial Bold 的平均重合度约 0.875，优于本次测试的其他候选。该指标只用于视觉试配，不是字体识别置信度，也不证明原谱使用 Arial Bold；归一化还忽略了原始尺寸、字宽和字距。
