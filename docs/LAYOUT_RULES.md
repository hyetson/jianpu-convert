# 单声部 4/4 初步排版

普通音符优先保留输入五线谱的符杠分组，只有缺少该信息时回退到 4/4 的四分音符拍内分组。2026-10-20 新增规则：含短休止的拍内，连续的短休止与普通短音符按一拍合并减时线，即使源谱将它们记为未连组；混排组不跨拍。输入事件、音高和时值均保留；合并的是减时线，不是音符事件。PDFKit 直接输出矢量 PDF。

以下尺寸为当前默认值，可通过 JSON 配置更改，具体字段见 [排版参数](LAYOUT_PARAMETERS.md)。

## 减时线

| 一拍内音型 | 第一层线 | 第二层线 |
| --- | --- | --- |
| 四个十六分 | 连续连接四个音 | 连续连接四个音 |
| 两个八分 | 连续连接两个音 | 无 |
| 十六分、八分、十六分 | 连续连接三个音 | 两端各保留短线 |
| 八分、十六分、十六分 | 连续连接三个音 | 仅连接最后两个音 |
| 附点八分、十六分 | 连接两个音 | 最后一个音保留短线 |
| 八分休止、八分音符（或反向） | 连接 0 与音符 | 无 |
| 十六分音符、十六分休止、八分音符 | 三个数字共用连续线 | 连接前两个数字 |
| 十六分休止、八分音符、十六分休止 | 三个数字共用连续线 | 两个 0 各保留短线 |

- 不含短休止的普通音符拍内仍由 MusicXML 每层 `beam` 决定减时线；原谱跨拍相连时保持相连，同拍内明确分成两组时仍分开。单向钩保留为独立短线。
- 含短休止的一拍按新规则处理：时间连续、没有重叠的普通短音符和短休止共用减时线，包含拍头/拍尾休止及拍内多个休止；每层按八分、十六分等音型分别连接。原谱跨越此混排拍边界的符杠在边界处断开。
- 未提供符杠元数据的纯音符组仍按 4/4 四分音符拍回退。倚音单独成组，连音组继续遵循明确源信息；整拍或更长的休止不纳入短音混排，不跨缺口连接。
- 混排按当前拍号的拍单位处理：2/4、3/4、4/4 等以四分音符为一拍；3/8 以八分音符为一拍，6/8、9/8、12/8 按三个八分单位为一组。复杂加法分组仍需原谱信息与专项确认。
- 低音点位于减时线下方；同拍合并时，以整组最下面一层减时线为参照，点与线留出间距。没有减时线的音符则在数字下方放置低音点。
- 升号、降号与还原号以较小字形放在数字左上方，字形之间保留约 0.5 pt 的水平间隙。普通升降号按字号的 0.3 倍预留横向宽度，重升、重降号及非整数变化音保留更多空间。
- 高音点以数字实际字形的上缘为参照，首个点的中心距上缘 3 pt，避免字体行框使高音点过远。
- 延时横线按字体实际数字字形的中部对齐，不使用文本行框的中部。

## 横向间距与断行

- 在音符所需宽度基础上给拍边界增加空隙；为升降号、还原号、附点及倚音预留额外宽度。
- 小节开头与结尾保留空隙；长音的延时横线和长休止中的后续 `0` 按实际拍位排列。
- 单声部小节内的可见音符组左右居中，包含升降号、减时线和延时横线的范围；只整体平移，不改变组内音符的相对节奏间距。小节线的上下端则以数字中线为中心。
- 小节基础宽度随拍数改变：以 4/4 为 100%，2/4 为 60%，3/4 为 80%，3/8 为 50%。音符、升降号、附点和倚音密集时，实际宽度以可读下限为准，不能按比例强压。
- 默认 `layout.meterAwarePacking: true`，每行以 `maxMeasuresPerSystem`（默认 4）个 4/4 小节为容量基准。2/4 小节各占 0.6 单位，因此一行可放六小节；音符过密时仍提前换行。设为 `false` 恢复实际小节数硬上限。`maxMeasuresPerSystem: 1` 始终保留单小节一行。
- 除末行外填满可用行宽；末行按自然宽度收尾，最后小节线无需对齐右页边。`layout.justifyLastSystem: true` 可恢复末行拉满。只调整已有小节，不添加空小节。
- 放入更多小节时优先压缩留白。每个音符间隔不低于原宽度的 82%，且必须满足数字、升降号、附点与拍间空隙的最低要求；数字字号保持不变。只有单小节本身仍超出行宽时，才缩小字号并报告警告。
- 初始主调、拍号以至少 14 pt 字号放在谱面最左端、第一小节号方框上方，左端对齐第一小节线；后续仅在变化处用 8 pt 标注变化的项目。换行、换页不重复标注，也不保留每行原来的调号/拍号栏。
- 保留每行起始小节号，外加方框；方框水平中心对齐该小节左侧小节线，并置于小节线上方。两位及更多位小节号按文字宽度扩展方框。
- 单声部省略左侧连接长竖线和每行乐器名，收回该区域作为排谱空间；普通小节线保留。
- 样张使用 A4、40 pt 页边距、14 pt 数字。断行已经综合整段小节的宽度；复杂技法的碰撞处理仍未覆盖。
